# AngelRaise Design System

## Aesthetic Direction
Modernized from original AngelRaise — orange brand + blue CTAs, friendly rounded sans-serifs, clean white backgrounds. Trustworthy but energetic.

## Color Roles
- **Orange (Brand)** — Logo, category badges, progress bars, accent text, brand elements
- **Blue (Primary)** — Main CTAs (Take Part, Watch Ad, Create Campaign), active nav links, interactive elements
- **Green (Success)** — Fully funded campaigns, completion states, success messages
- **Amber (Warning)** — Almost funded (>80%), urgency cues
